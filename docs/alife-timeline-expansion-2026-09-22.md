# 人工生命时间线扩充记录（2026-09-22）

此次按跨方向口径整理项目：认知架构、持续智能体、社会模拟、世界模型、叙事交互、经典人工生命、具身与仿真平台均可收录。共享目录从 39 条增加到 182 条，新增 143 条；主页与独立展览读取同一份数据。

年份表示条目所注明的论文、公开版本或产品发布里程碑，不统一宣称为项目创立年。仅能确认当前仓库创建时间的条目明确写明这一限制。研究愿景、架构图式、商业游戏和运行中的研究系统在描述中区分；不能把视频一致性视为严格持续的世界状态，也不能把角色行为视为意识证据。
