# Fount 0.1.5

## Highlights

- Add a visible configuration and credential readiness panel to the Release Steward Field.
- Show the concrete status of the official website, GitHub release repo, Discord channel, Telegram setup, hot-update manifest, and approval gate.
- Wire Discord community publishing to the Fount server announcement channel while keeping secrets in local ignored files.

## Changes

- Release Steward now shows release targets, credential sources, current readiness, and missing next steps without exposing tokens or webhook URLs.
- The release command preview now matches the actual `release/publish-release.mjs` arguments used by the publishing pipeline.
- Release Steward sample state now reflects the current 0.1.5 release flow instead of the older 0.1.1 rehearsal data.

## Notes

- Telegram community publishing is intentionally left disabled until a valid bot token and target chat id are configured.
- Discord, website, GitHub release, public release notes, and static hot-update manifest publishing are enabled for the current Fount release pipeline.
